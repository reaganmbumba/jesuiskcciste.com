Dernier enregistrement

⬇ Enregistrer sur le téléphone

Envoyer sur la chaîne YouTube

1 · Enregistrer puis publier sur YouTube

  1. Touchez ● Enregistrer, faites votre émission, puis ■ Arrêter.
  2. Touchez ⬇ Enregistrer sur le téléphone : la vidéo va dans vos téléchargements.
  3. Touchez ↗ Partager et choisissez YouTube (ou WhatsApp, Facebook).
  4. Pour la miniature YouTube, choisissez une belle image et touchez 📸 Miniature.

2 · Direct YouTube depuis le téléphone

Un site internet ne peut pas envoyer lui-même l'image à YouTube. On passe par une application de direct qui diffuse l'écran du téléphone.
  1. Installez une application de direct qui sait « diffuser l'écran » vers YouTube (par exemple Prism Live Studio ou Streamlabs) et reliez-la à la chaîne Je suis KCCiste.
  2. Dans l'application, choisissez la diffusion de l'écran, puis revenez ici.
  3. Touchez ⛶ Mode diffusion : seule l'image du studio reste à l'écran, en plein écran. Touchez deux fois l'écran pour revenir aux réglages.

Diffuser en même temps sur YouTube, Facebook et d'autres réseaux

Pour un seul direct visible à la fois sur YouTube, Facebook, TikTok…, on passe par un service de « multidiffusion », relié une fois à chaque compte :
  1. Sur téléphone : une application de direct qui sait diffuser vers plusieurs réseaux à la fois (par exemple Prism Live Studio). Reliez-y la chaîne YouTube et la page Facebook, choisissez la diffusion de l'écran, puis touchez ici ⛶ Mode diffusion.
  2. Sur ordinateur : OBS avec un service comme Restream, qui renvoie le direct vers YouTube, Facebook et les autres réseaux reliés.
  3. Pendant le direct, touchez Annoncer le direct (onglet Direct) pour envoyer le lien dans les groupes WhatsApp et sur Facebook.

3 · Direct YouTube depuis un ordinateur (OBS)

Dans OBS Studio, ajoutez une Source navigateur avec le lien ci-dessous (1920 × 1080). Elle pose l'habillage Je suis KCCiste (logo, badge, titre, bandeaux) par-dessus votre caméra, sur fond transparent. Le lien reprend les textes réglés ici : recopiez-le après chaque changement.
⚙ Réglage de l'envoi direct sur YouTube (déjà fait pour la chaîne Je suis KCCiste)
  1. Sur un ordinateur, ouvrez console.cloud.google.com avec le compte Google de la chaîne et créez un projet « Je suis KCCiste ».
  2. Dans « API et services › Bibliothèque », activez YouTube Data API v3.
  3. Dans « Écran de consentement OAuth », choisissez « Externe », nom « Je suis KCCiste », et ajoutez votre adresse comme utilisateur test.
  4. Dans « Identifiants », créez un ID client OAuth de type « Application Web », avec l'origine autorisée https://jesuiskcciste.com.
  5. Copiez l'ID client (il finit par .apps.googleusercontent.com) et collez-le ci-dessous.

Tant que Google n'a pas vérifié le projet, YouTube garde les vidéos envoyées ainsi en « Privée » : il suffit alors de les passer en « Publique » dans YouTube Studio.
