KCC Studio CaméraJe suis KCCiste · régie de direct

Ce téléphone peut devenir une caméra de la régie. Il faut l'application KCC Studio Caméra (Android).

⬇ Télécharger l'application
  1. Ouvrez le fichier téléchargé KCC-Studio-Camera.apk.
  2. Si le téléphone le demande, autorisez « Installer des applications inconnues » pour le navigateur, puis touchez Installer.
  3. Ouvrez KCC Studio Caméra, autorisez la caméra et le micro.
  4. Touchez Scanner le code de la régie et visez le code affiché sur le PC.

Déjà installée ? Ouvrez simplement l'application et scannez le code.
